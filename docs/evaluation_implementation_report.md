# 测评改进实施与验证（2026-10-11）

测评代码已按 [实施计划](evaluation_plan.md) 接入当前患者归属、会话内上下文与跨会话本人画像规则。保持 LangGraph 的修订循环，不增加 ReAct 层或记忆管理面板。使用方法见 [testing.md](testing.md)。

## 已实现

- 显式 Mock、真实核心和完整检索模式；独立临时数据库、逐依赖检查、不可变报告及代码/数据/语料/配置指纹。依赖不足、执行失败、评分失败和未完成有不同状态及非零退出码。
- 会话专项按 fixed/multi 配对执行，检查模型实际生效输入、患者归属、来源、否认、病程、画像确认/撤销、附件隔离、最终事件与保存一致性。禁止信息断言必须确实触发上下文流程，不能因没有模型输入而通过。
- 检索候选与实际最终证据分层统计；实际应用答复与采用摘录送独立 judge，严格验证评分 Schema；安全单独作为门槛。
- Agent 必要工具、合理替代组、结构与已标注参数语义、修订轮次依赖、取消幂等、故障和越权检查。
- 实际 HTTP/SSE 与浏览器入口，按模式、场景、并发统计最终可见答案耗时、失败、usage 覆盖与费用。缺失 usage/价格保留 unknown。
- 数据家族/重复/冻结审查、盲评队列、配对版本比较及 CI 离线契约门禁。发布策略在运行前绑定哈希，发布审核还要求同版本真实部署负载达到已声明目标。

验证中修正了 Windows 检查点连接未及时关闭和运行清理未完成的生命周期问题；临时 Chroma 只关闭本次测评的索引，不影响其他索引。回环地址直连，避免 Windows 系统代理阻断本地部署检查。

部署补测进一步修复删除会话时同步等待检查点锁、阻塞异步写入者的故障：检查点清理移到工作线程，增加写锁等待时事件循环仍能推进的回归。驱动现在将清理失败纳入请求失败，分别记录缺少最终答复、事件顺序、超时及其耗时。

## 检索与真实质量的边界

本次 46 个 RAG 问句在 BM25 离线模式下候选 Hit@5 为 93.5%，但最终字面准入的引用为空率为 100%，最终相关率为 unknown、召回率为 0。它说明候选命中不能代替最终证据效果。执行门禁只验证链路和来源契约；不会把这组结果解释成检索质量验收通过，也未改变生产准入门槛来提高得分。完整混合检索、CrossEncoder/MMR 和真实回答须使用 live_full 另测。

当前 live_core 依赖检查明确阻止运行，原生进程退出码为 2。缺少配置名称：`QIWEN_MODEL_NAME`、`QIWEN_JUDGE_BASE_URL`、`QIWEN_JUDGE_API_KEY`、`QIWEN_JUDGE_MODEL`。没有真实质量评分，也没有静默切换到 Mock 后宣布通过。

专业片段标签、冻结验收数据、人工复核、预先声明的质量/部署 SLA 仍需实际完成。代码提供流程，不伪造这些结果。已导出本次 30 条安全答复的待复核队列；没有将其标记为已审核。
