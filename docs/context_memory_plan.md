# 岐问会话记忆与上下文修改计划及实施

## 当前边界（2026-10-10 修订）

岐问用于中医知识问答、连续症状咨询、代亲属咨询及病历解释。会话内记住明确自述、否认、更正、时间和待答问题；跨会话只参考用户手填或明确确认保存的本人画像。其他会话的症状、病历附件、病程摘要和待答问题没有自动参考作用。

## 完整修改范围

1. 撤除“问诊信息与记忆”入口、弹窗、组件、专用 API 方法、类型及测试，保留已有画像管理，不新增替代设置页。
2. 移除主工作流及 Agent 的跨会话摘要检索、嵌入、重排、运行级缓存与发布；移除 memory_rerank 模型角色，不允许旧环境变量绕过 Mock 模式。
3. 会话内保留结构化症状、安全事实、来源、病程与滚动摘要。明确新问题归档旧症状；同会话长间隔按需确认是否延续，默认 14 天为交互阈值，不是医学有效期。
4. 跨会话画像只限本人且对象已确认。过敏等长期资料作为背景；用药、孕哺等时效事实按新会话或病程变化复核。临时症状和模型辨证/候选方剂不自动升级为画像，代问不套用本人资料。
5. 保留画像确认、修改、撤销、版本与指纹检查，以及问诊状态、候选审查的事务一致性；取消和失败不推进会话摘要。避免旧请求恢复撤销资料。
6. 移除独立记忆列表和会话上下文展示接口。已有摘要删除和旧控制 API 兼容保留；设置开启也不再触发自动症状记忆。数据库不清空，不擅自重置已关闭状态。
7. 旧摘要、词索引、向量与归属表留存用于兼容和显式删除，不查询、不回填。旧检查点的跨会话记忆字段不导入新流程，历史摘要来源的风险事实被排除。
8. 保留共享 ContextBundle、实际模型调用前预算、同会话知识话题、受权限约束的附件源读取、检查点保留策略及 LangGraph 工具循环。

## 实施位置

- `workflow.py`：`profile_load` 只加载符合对象条件的画像及同会话资料；`episode_write` 生成会话内摘要，结束阶段无历史摘要压缩分支。
- `main.py`：病程摘要与成功答复事务提交，彻底停止向 profile_memories 发布；画像读取不返回历史症状摘要，移除展示接口。
- `context.py`、`safety_context.py`、`safety_store.py`：排除旧摘要输入和风险提示，保留适用画像与当前会话事实。
- `agents/tools.py`、`agents/multi.py`、`model.py`：移除 search_memories、memory_rerank 和相关调用缓存。
- `memory.py`：仅保留旧记录删除、控制版本及画像更正后的旧派生数据失效。
- 前端移除 MemoryPanel 及专用客户端契约；保留已确认画像、聊天更正及会话删除。

## 验收场景

| 场景 | 必须满足 |
| --- | --- |
| 会话 A 咳嗽三天，新会话 B 头痛 | B 不含 A 症状、摘要、附件和待答问题；符合条件的本人画像可参考 |
| 同会话咳嗽三天 → 夜间明显 → 没有发热 | 时长、变化、否认及原始来源保留 |
| 同会话长间隔或明确新问题 | 按需确认延续或新病程，旧症状不无条件视为当前 |
| 本人 → 母亲 → 本人 | 对象和待答问题各自恢复，亲属不读本人画像 |
| 画像过敏确认、更正或撤销 | 跨会话可参考有效画像，旧请求不能回写过期结果 |
| 旧摘要及检查点存在 | 不注入模型；不生成新的跨会话摘要；旧数据和禁用状态不自动清空/重置 |
| 知识追问穿插问诊 | 同会话知识话题可承接，纯知识请求不含患者资料 |
| 取消、失败、删会话 | 不推进成功摘要，删除保持权限和级联一致性 |
| 长病历与工具循环 | 每次模型请求预算受控，必要风险信息不静默裁掉 |

## 验证与交付

执行受影响回归、后端完整回归、前端测试、lint 和生产构建。每次前后端或运行配置修改后执行 `docker compose up --build -d`，随后检查前后端 healthy、`http://127.0.0.1:23000/api/health` 和 `/chat` 可访问。测试使用合成数据和 Mock，不宣称真实模型的医学质量已验证。

最终验证：后端完整回归 254 项通过（256.86 秒），前端 67 项测试通过，lint 零警告、生产构建及 TypeScript 检查通过。补充覆盖单一症状的“夜间明显”等省略描述，保留原始时长与补充描述各自来源，多个症状时不猜测归属。旧召回/重排测试随对应功能撤除，由会话边界、旧状态排除、画像复用和会话连续性测试替代。

`docker compose up --build -d` 完成；前后端均 healthy，`/api/health`、`/chat` 均 HTTP 200。容器内 12 个后端及 3 个前端关键文件哈希与工作区一致，MemoryPanel 文件已移除。旧摘要与禁用状态保留，所有运行路径不再发布或召回跨会话症状摘要。
