## 模型调用

- 服务端请求走 acomplete / acomplete_json，使用异步 HTTP 响应上下文；取消或超时关闭响应和客户端。
- 每次调用独立超时，默认 45 秒、额外重试 2 次；超时限制 0.05～300 秒、额外重试 0～5 次。退避最多 2 秒。401、无效 JSON、Schema 不合规不重试；408、429、5xx 和传输异常在上限内重试。Schema 严格本地校验，不要求供应商支持 response_format。
- 11 个角色可通过 QIWEN_MODEL_<ROLE> 更换模型，留空回退 QIWEN_MODEL_NAME；_TIMEOUT / _RETRIES 留空也回退默认值。全部共享接口地址与密钥。
- 本轮实际模型节点为安全预审、辨证、方剂与多专家审查。问诊、本草、综合、摘要、画像提取、检索评估、查询改写的角色入口已注册，现有规则或模板节点尚未改成模型实现；相应配置在接入模型后才影响问答。接口测试逐一验证全部角色覆盖与回退。
- 元数据记录角色、模型、耗时、输入/输出 Token、重试次数、每次尝试和最终状态，不保存提示词、正文、密钥。供应商未返回用量时为 null，前端显示“未知”；不能据此推断取消请求的实际计费。

## 安全预审规则 v1

这是独立的工程拦截标准，**尚未完成医学专家复核**，不能作为临床风险分级规范。规则位于 preflight.py、workflow.py、safety.py；模型只能加强规则结论。allow 只允许继续流程，不表示治疗安全。

| 风险类别 | 工程判断 | 路径与预期 |
| --- | --- | --- |
| 严重症状 | 当前文本或附件命中既有急症词：胸痛、呼吸困难、昏厥、大出血、意识不清、自杀 | block，及时就医提示，不生成候选 |
| 危险配伍 | 加药/合用请求与同会话已展示方案合并，命中十八反十九畏 | block，确定性规则优先 |
| 孕哺 | 肯定描述或画像既往史出现孕期、备孕、哺乳等 | 至少 clarify，要求医师核对 |
| 儿童 | 描述出现未满 18 岁的数字年龄或儿童、宝宝等词 | 至少 clarify，要求年龄与就诊资料 |
| 合并用药 | 规则识别正在服药、抗凝药、降压药等 | 至少 clarify，要求完整用药与病史 |
| 过敏 | 当前肯定描述中的已收录药材、手填过敏史 | 纳入候选校验；过敏原不明时 clarify；自述只对本轮生效，不自动覆盖画像 |
| 绕过要求 | 请求忽略、绕过、关闭安全规则等 | block，不生成候选 |
| 模型异常 | 超时、重试耗尽、无效结构 | block，不进入辨证或方剂 |
| 不可解析候选 | 缺失/非列表药材、未知药名、不合规的剂量、单位或出处 | 不标安全，拒绝该版本，重试耗尽输出受限答复 |

急症词匹配可能误拦截否定描述或旧病历；其他规则也是保守启发式，不能识别所有表达。合成案例覆盖这些类别；误放行/误拦截和医学判断仍需人工复核。配伍依据见 [深圳市《中药饮片处方审核规范》附录 C](https://wjw.sz.gov.cn/attachment/0/758/758943/8708423.pdf)。

预审结构含 decision、risk_categories、reason、required_questions。模型风险解释和问题不直接作为正文公开，避免夹带治疗指令。自由正文与专家卡检查剂量/用法；允许的剂量从结构化数据生成方剂段与卡片，缺少依据或核验时保留空值/未核验。古籍摘录含相关内容时省略摘录并保留出处。

## 运行与取消

1. 客户端提交 run_id（可选，省略时生成），校验归属后保存运行和用户消息；相同 ID 不可重用，同会话只能有一个运行中的任务。
2. SSE 首事件返回运行与候选标识；实际节点开始/完成事件带次数和耗时，区分 preparation、generation、review。候选实时显示，拒绝后用新 candidate_id 替换，最终检查和事务提交后发 answer.final。
3. POST /api/runs/{run_id}/cancel 校验归属，标记 cancelling，取消任务并等待响应/图清理，保存 cancelled。重复调用幂等；断开和退出也清理。ASGI 2.3 / 2.4 均有断开测试。
4. 取消停止后续节点、重试、成功提交。摘要节点只准备数据，答复和摘要在同一事务中提交；取消仅保存“已停止”及轨迹，不写成功结果或画像。
5. 运行有独立检查点，下一轮只读同会话最近 completed 运行。取消检查点不会续接；升级仍可读旧会话检查点。重启将遗留 running/cancelling 转为 cancelled。
6. 最终消息、摘要、候选和最终事件一起保存，再发送 answer.final；完成后的取消无操作。发送时断开或刷新仍能恢复已完成结果。前端重读历史保留服务端元数据，不加载被拒版本。
7. GET /api/runs/{run_id} 查看状态和元数据；会话“处理流程”可展开节点时间与模型用量。阶段墙钟区间累积重试，并行节点时间不能直接相加当总时间。发送耗时指服务端循环，不代表浏览器接收延迟。

当前 Docker 为单个 Uvicorn 进程，活动任务在进程内管理；增加 worker/副本前需共享运行协调器。上游停止计算/计费待供应商验证。只读同步检索在线程中执行，取消停止图调度但不会强行终止已经开始的检索；该线程不写患者数据。

## 可复现验收

项目根目录：

~~~powershell
.venv\Scripts\python.exe -m pytest backend/tests -q -p no:cacheprovider
~~~

backend 目录：

~~~powershell
..\.venv\Scripts\python.exe -m evaluation.runner --output ../.data/evaluation-baseline-latest.json
..\.venv\Scripts\python.exe -m scripts.check_core_live --output ../.data/core-live-latest.json
~~~
